Best agent builder

Build AI agents and multi-step workflows.

The ranking

  1. n8n (freemium): Fair-code workflow automation with AI agent nodes; self-hostable.
  2. LangGraph (freemium): Developer framework for stateful, controllable agents.
  3. CrewAI (freemium): Multi-agent orchestration framework plus hosted platform.
  4. Relevance AI (freemium): No-code platform for building AI agent teams.

  8. Google ADK (free): Google's open-source Agent Development Kit.
  9. Microsoft Agent Framework (free): Microsoft's open-source successor to AutoGen and Semantic Kernel agents.
  10. LlamaIndex (freemium): Framework and cloud for agents over your documents.
  11. Pydantic AI (free): Type-safe Python agent framework from the Pydantic team.
  12. Mastra (free): Open-source TypeScript agent framework.
  13. Dify (freemium): Open-source platform for building LLM apps and agent workflows visually.
  14. Flowise (free): Open-source drag-and-drop builder for LLM agents.
  15. Langflow (free): Open-source visual builder for agents and RAG.
  16. Lindy (freemium): No-code AI agents for business tasks like email and scheduling.
  17. Botpress (freemium): Platform for building AI chat agents.
  18. Voiceflow (freemium): Platform to design and deploy chat and voice agents.
  19. Vapi (paid): Developer platform for voice AI agents.
  20. Agno (free): Open-source Python framework and runtime for multi-agent systems.
  21. Monid (freemium): OpenRouter for agent tools. New open-source launch on GitHub.
  22. agent-memory (free): Long-term memory runtime for agents with plain Markdown as source of truth. New open-source launch on GitHub.
  23. Reef (freemium): Infrastructure for continually self-improving agents. New open-source launch on GitHub.
