Best self-hosted and open-source AI coding tools

Updated 22 Oct 2026 · Prices from vendor pages only · How we rank →

The short answer

Each of these AI coding tools can run on your own machine or servers, or is open source. OpenHands comes first: MIT-licensed, model-agnostic agent with a web GUI, CLI and SDK. It runs free locally with unlimited conversations, there's a free cloud Individual tier, and the GitHub community is large (about 91K stars). The cheapest verified paid plan here is Kilo Code Teams ($15/user/month). 10 of the 10 have a free plan we could confirm. Every price below is from the vendor’s own page, checked 16–19 Oct 2026.

Ranked shortlist

  1. OpenHands: MIT-licensed, model-agnostic agent with a web GUI, CLI and SDK. It runs free locally with unlimited conversations, there's a free cloud Individual tier, and the GitHub community is large (about 91K stars). Plan: Local (open source): Free
    Unlimited conversations
  2. Aider: Free and open source (Apache-2.0). Works with almost any LLM, including local ones, maps your whole codebase and commits each change to git so it's easy to undo. Plan: Free, open source: you pay only your LLM provider
  3. Gemini CLI: Google's open-source terminal coding agent powered by Gemini. Plan: Open source (Apache-2.0); sign in with a Google account or use a Gemini API key
  4. Kilo Code: Open-source coding agent for VS Code and JetBrains. Plan: Free & Open Source: Free
  5. Dyad: Free, local, open-source app builder; bring your own model keys. Plan: Dyad Free: Free
  6. OpenCode: Open-source terminal coding agent supporting many models. Plan: Open source; free models included or bring any provider
  7. vibe-wise: Claude Code/Codex plugin that teaches you to build while AI writes the code. New open-source launch on GitHub. Plan: Open source (MIT)
  8. scroll-craft: Agent skill for building premium scroll-driven websites. New open-source launch on GitHub. Plan: Open source (MIT)
  9. shadcn lint: Agent-first linter for Tailwind design systems. New open-source launch on GitHub. Plan: Open source (MIT)
  10. jevgrep: CLI for coding agents to find code by asking what it does. New open-source launch on GitHub. Plan: Open source (MIT)

Order follows ToolRank’s editorial ranking in Coding & App Building, filtered to tools that fit this page. Anything we couldn’t confirm on a vendor page says “Not yet verified”.

Who should pick which

Pick OpenHands for teams that want an autonomous agent they can self-host and audit (Local: open source) (Free); think twice if you want an inline autocomplete assistant inside your editor. Pick Aider for terminal users who want a free, model-agnostic pair programmer with clean git history (free plan: Free, open source: you pay only your LLM provider); think twice if you want a polished IDE, a hosted service, or one bundled subscription. Pick Gemini CLI for terminal users who want Google's open-source coding agent (free plan: Open source (Apache-2.0); sign in with a Google account or use a Gemini API key). Watch out: the README says it is not optimised for the latest Gemini models and points to Antigravity CLI. Pick Kilo Code for open-source coding agent with any model (Free & Open Source: Free). Watch out: model usage costs extra. Pick Dyad for building apps locally with any model (Dyad Free: Free). Watch out: desktop app only. Pick OpenCode for terminal users wanting an open-source coding agent (free plan: Open source; free models included or bring any provider). Watch out: you pay your model provider for paid models. Pick vibe-wise for beginners who want to learn how their app is built while an AI agent writes the code (free plan: Open source (MIT)). Watch out: a plugin, not an app: you need Claude Code or Codex.
