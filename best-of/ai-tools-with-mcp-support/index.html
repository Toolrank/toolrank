Best AI tools with MCP support (all categories)

Updated 16 Oct 2026 · Prices from vendor pages only · How we rank →

The short answer

Each of these tools, across all categories, supports the Model Context Protocol. GitHub Copilot comes first: works in most major editors and in GitHub itself, from a free plan up to cloud agents and code review. The cheapest verified paid plan here is GitHub Copilot Pro ($10/month). 10 of the 10 have a free plan we could confirm. Every price below is from the vendor’s own page, checked 16 Oct 2026.

Ranked shortlist

  1. GitHub Copilot: Works in most major editors and in GitHub itself, from a free plan up to cloud agents and code review. Plan: Pro: $10/month
  2. Cline: Free, open-source (Apache-2.0) agent with no subscription or seat fees: you pay for inference only, at cost or with your own keys, from many providers. Plan: Free for individuals: pay only for AI inference (BYOK or at cost)
  3. Kiro: AWS's main coding product: spec-driven development, hooks and steering in a VS Code-based IDE plus CLI. It has a perpetual free tier, and it's the official successor to Amazon Q Developer. Plan: Pro: $20/user/month
  4. OpenHands: MIT-licensed, model-agnostic agent with a web GUI, CLI and SDK. It runs free locally with unlimited conversations, there's a free cloud Individual tier, and the GitHub community is large (about 91K stars). Plan: Open source: free, unlimited local use. Cloud Individual: free, 10 conversations/day, BYOK or at-cost models
  5. Webflow: Visual website builder with AI site and page generation. Plan: Basic: $15/month billed yearly
  6. Amazon Q Developer: Ranked low because AWS is retiring it. New sign-ups closed on 15 May 2026, the CLI became Kiro CLI, and IDE plugins and paid subscriptions reach end of support on 30 Apr 2027. Plan: Pro: $19/user/month
    Higher limits, 4,000 LOC/month pooled, admin dashboard
  7. Runway: Leading video models with clear credit-based plans and mobile apps. Plan: Standard: $12/month annual ($15 monthly)
    625 credits/month
  8. Pika: Text- and image-to-video generator with effects for short social clips. Plan: Starter: $10/month ($8 annual)
    900 credits/month, no commercial license
  9. OpusClip: Turns long videos into short vertical clips automatically. Plan: Starter: $15/month
    No watermark, YouTube auto-import
  10. Zapier: The largest app ecosystem with a free forever plan and simple task-based pricing. Plan: Professional: from $19.99/month
    Multi-step Zaps

Tools come from several ToolRank categories, so they are grouped by category and then by each category’s editorial rank. Anything we couldn’t confirm on a vendor page says “Not yet verified”.

Who should pick which

Pick GitHub Copilot for teams already on GitHub who want AI in their existing IDE (Pro: $10/month); think twice if you want an AI-native editor rather than a plugin. Pick Cline for developers who want a transparent, model-agnostic agent in VS Code and control over spend (free plan: Free for individuals: pay only for AI inference (BYOK or at cost)); think twice if you want one flat monthly price. Pick Kiro for teams on AWS that want structured, spec-first agent work (Pro: $20/user/month); think twice if you want unmetered use or a plugin for Visual Studio/Eclipse. Pick OpenHands for teams that want an autonomous agent they can self-host and audit (free plan: Open source: free, unlimited local use. Cloud Individual: free, 10 conversations/day, BYOK or at-cost models); think twice if you want an inline autocomplete assistant inside your editor. Pick Webflow for designer-grade marketing sites (Basic: $15/month billed yearly). Watch out: site and workspace plans are billed separately. Pick Amazon Q Developer for existing AWS customers finishing Java/.NET transformations before the cutoff (Pro: $19/user/month); think twice if you're starting fresh. AWS points new users to Kiro. Pick Runway for creators and studios producing AI video (Standard: $12/month annual ($15 monthly)); think twice if you need long-form video on a small budget.
