Who should pick which

Pick Rosebud AI for hobbyists and educators prototyping games (Indie Dev: $15/month); think twice if you're building a commercial engine-based game. Pick Scenario for game studios needing style-consistent assets (Starter: $15/month); think twice if you need general marketing images. Pick Ludo.ai for indie developers researching and prototyping game ideas (Indie: $15/month paid annually); think twice if you only need a single asset type. Pick Sloyd for indie game developers who want unlimited 3D generations with a commercial licence (Sloyd Plus: $12.50/month billed yearly ($150/year); $15/month monthly). Watch out: the free plan is personal-use only with 1 AI generation a day; API credits are billed separately.
