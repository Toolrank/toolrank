Best AI coding tools for JetBrains IDEs

Updated 17 Oct 2026 · Prices from vendor pages only · How we rank →

The short answer

Each of these tools lists JetBrains IDE support. GitHub Copilot comes first: works in most major editors and in GitHub itself, from a free plan up to cloud agents and code review. The cheapest verified paid plan here is GitHub Copilot Pro ($10/month). 5 of the 8 have a free plan we could confirm. Every price below is from the vendor’s own page, checked 16 Oct 2026.

Ranked shortlist

  1. GitHub Copilot: Works in most major editors and in GitHub itself, from a free plan up to cloud agents and code review. Plan: Pro: $10/month
  2. Cline: Free, open-source (Apache-2.0) agent with no subscription or seat fees: you pay for inference only, at cost or with your own keys, from many providers. Plan: Free for individuals: pay only for AI inference (BYOK or at cost)
  3. JetBrains AI (Junie): Built into IntelliJ IDEA, PyCharm and the other JetBrains IDEs. JetBrains Air runs Junie, Claude Agent, Codex and other agents, and lets you bring your own keys. Plan: AI Pro: $10/month ($100/year)
    Personal pricing
  4. Kilo Code: Open-source coding agent for VS Code and JetBrains. Plan: Teams: $15/user/month
  5. Augment Code: Coding agent built for large codebases with deep context. Plan: Standard: $20/month flat
    $20 usage included
  6. Cody (Sourcegraph): Ranked low for most readers: Cody Free and Pro closed to new sign-ups in June 2025 and were discontinued. It survives only inside Sourcegraph Enterprise, where its strength is whole-codebase context. Plan: Not yet verified
  7. Amazon Q Developer: Ranked low because AWS is retiring it. New sign-ups closed on 15 May 2026, the CLI became Kiro CLI, and IDE plugins and paid subscriptions reach end of support on 30 Apr 2027. Plan: Pro: $19/user/month
    Higher limits, 4,000 LOC/month pooled, admin dashboard
  8. Continue: Ranked low because it is discontinued. Continue was acquired by Cursor, its repo is read-only, and 2.0.0 was the last release. The open-source extension still runs with your own keys or local models. Plan: Open-source extension (Apache-2.0), self-run with your own model keys

Order follows ToolRank’s editorial ranking in Coding & App Building, filtered to tools that fit this page. Anything we couldn’t confirm on a vendor page says “Not yet verified”.

Who should pick which

Pick GitHub Copilot for teams already on GitHub who want AI in their existing IDE (Pro: $10/month); think twice if you want an AI-native editor rather than a plugin. Pick Cline for developers who want a transparent, model-agnostic agent in VS Code and control over spend (free plan: Free for individuals: pay only for AI inference (BYOK or at cost)); think twice if you want one flat monthly price. Pick JetBrains AI (Junie) for developers already living in JetBrains IDEs (AI Pro: $10/month ($100/year)); think twice if you don't use JetBrains IDEs. Pick Kilo Code for open-source coding agent with any model (Teams: $15/user/month). Watch out: model usage costs extra. Pick Augment Code for teams wanting a flat-price coding agent (Standard: $20/month flat). Watch out: usage beyond the included amount is billed. Pick Cody (Sourcegraph) for large organisations already on Sourcegraph Enterprise ($16K/year minimum (Sourcegraph Enterprise)); think twice if you're an individual or small team. Sourcegraph pointed Cody Free/Pro users to Amp. Pick Amazon Q Developer for existing AWS customers finishing Java/.NET transformations before the cutoff (Pro: $19/user/month); think twice if you're starting fresh. AWS points new users to Kiro.

FAQ

Which of these is cheapest?

GitHub Copilot Pro ($10/month) is the lowest paid price we verified on this list (https://github.com/features/copilot/plans, checked 16 Oct 2026). Check the vendor page for tax, billing period and usage limits.

Which of these have a free plan?

GitHub Copilot: Limited chat and agent usage; no code review or cloud agent; Cline: Free for individuals: pay only for AI inference (BYOK or at cost); Kilo Code: Free and open source; AI usage billed separately; Amazon Q Developer: 50 agentic requests/month (existing accounts only; new sign-ups closed 15 May 2026); Continue: Open-source extension (Apache-2.0), self-run with your own model keys.

How were these tools chosen?

They are the tools in ToolRank's rankings with JetBrains listed as a supported platform, confirmed on the vendor's own website on 16 Oct 2026. Tools we could not verify are left out rather than guessed, and anything unconfirmed is marked Not yet verified.
