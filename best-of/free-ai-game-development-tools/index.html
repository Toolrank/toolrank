Who should pick which

Pick Rosebud AI for hobbyists and educators prototyping games (free plan: 8,000 starting credits, no card; refills in eligible regions); think twice if you're building a commercial engine-based game. Pick Scenario for game studios needing style-consistent assets ($15/month (Starter)); think twice if you need general marketing images. Pick Meshy for game devs and 3D printers needing quick models (Free: $0); think twice if you need production-grade hand-modelled topology. Pick Inworld AI for developers building voice-driven games and apps (On-Demand: $0 + usage); think twice if you want a no-code tool.
