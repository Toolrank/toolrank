Best AI coding tools for teams (per-seat plans)

Updated 18 Oct 2026 · Prices from vendor pages only · How we rank →

The short answer

Each of these AI coding tools sells a team, business or per-seat plan, so you can put several people on one bill. Cursor comes first: a full AI-native editor with agents, cloud automations and code review, and a free tier to start. The cheapest verified paid plan here is Cursor Plus ($8/month). 9 of the 10 have a free plan we could confirm. Every price below is from the vendor’s own page, checked 16 Oct 2026.

Ranked shortlist

  1. Cursor: A full AI-native editor with agents, cloud automations and code review, and a free tier to start. Plan: Teams: $30+/user/month
    Pooled usage
  2. Claude Code: Anthropic's agentic coder runs in your terminal and repo, included with Claude paid plans. Plan: Team premium seat: $100/seat/month annual
    Includes Claude Code and Claude Cowork
  3. Bolt.new: Generous token-based free tier and simple Pro/Teams pricing for in-browser app building. Plan: Teams: $30/member/month
    Centralized billing
  4. Windsurf: Full agentic IDE with a free plan and unlimited Tab completions. Since June 2026 it ships as Devin Desktop, with a Kanban-style Agent Command Center that runs Devin and third-party ACP agents. Plan: Teams: $80/month minimum + $40 per full seat
    Up to 200 users, admin dashboard
  5. v0: Vercel's generator for React/Next.js UIs and apps, deploys to Vercel. Plan: Business: $100/user/month
  6. Devin: Delegates whole tickets to a cloud agent that plans, writes code and opens PRs. It connects to Slack, Linear, Jira and your git host, and since 2026 the self-serve plans start free. Plan: Teams: $80/month minimum + $40 per full seat
    Up to 200 users, admin dashboard
  7. Kiro: AWS's main coding product: spec-driven development, hooks and steering in a VS Code-based IDE plus CLI. It has a perpetual free tier, and it's the official successor to Amazon Q Developer. Plan: Pro: $20/user/month
  8. Zed: A very fast native editor that's free forever with your own keys or external agents like Claude Agent and Codex CLI. Pro is a low $10/month. Plan: Business: $30/seat/month
    Org AI policies, data governance, RBAC
  9. Amp: A frontier coding agent that is free to start with your own keys or subscriptions, and has no Amp token fees on BYOK. It became an independent company after spinning out of Sourcegraph in Dec 2025. Plan: Teams: No extra charge
    Shared billing, SSO
  10. Kilo Code: Open-source coding agent for VS Code and JetBrains. Plan: Teams: $15/user/month

Order follows ToolRank’s editorial ranking in Coding & App Building, filtered to tools that fit this page. Anything we couldn’t confirm on a vendor page says “Not yet verified”.

Who should pick which

Pick Cursor for developers who want an AI-first editor with agents and code review (Teams: $30+/user/month); think twice if you want flat pricing that includes third-party models. Pick Claude Code for developers who prefer terminal-driven agents working across a repo (Team premium seat: $100/seat/month annual); think twice if you want a free tool or a graphical editor experience. Pick Bolt.new for quick full-stack prototypes and small business apps (Teams: $30/member/month); think twice if you'll burn through tokens on large projects without budget for upgrades. Pick Windsurf for developers who want a VS Code-style IDE that manages several local and cloud agents from one screen (Teams: $80/month minimum + $40 per full seat); think twice if you want a stable, unchanging product, or a flat price with no usage overages. Pick v0 for generating React/Next.js UI and deploying to Vercel (Business: $100/user/month). Watch out: usage is credit-based. Pick Devin for teams that want to hand well-scoped tickets to an agent and review the PRs (Teams: $80/month minimum + $40 per full seat); think twice if you want to stay hands-on in your editor, or you can't give an agent repo access. Pick Kiro for teams on AWS that want structured, spec-first agent work (Pro: $20/user/month); think twice if you want unmetered use or a plugin for Visual Studio/Eclipse.

FAQ

Which of these is cheapest?

Cursor Plus ($8/month) is the lowest paid price we verified on this list (https://cursor.com/pricing, checked 16 Oct 2026). Check the vendor page for tax, billing period and usage limits.

Which of these have a free plan?

Cursor: Free: limited agent requests and limited chat requests; Bolt.new: 300K tokens/day, 1M tokens/month, Bolt branding, 10MB uploads, unlimited databases; Windsurf: Light agent quota, limited models, unlimited inline edits and Tab completions; v0: Free: $0/month, deploy apps to Vercel; Devin: Free plan: light quota, limited models (no cloud agents); Kiro: Perpetual free tier: 50 credits, Claude Sonnet 4.5 and open-weight models, rate-limited; Zed: Personal: free forever, unlimited with your own API keys or external agents; Amp: Hobby: free, all features, BYOK, pay-as-you-go orb runtime; Kilo Code: Free and open source; AI usage billed separately.
