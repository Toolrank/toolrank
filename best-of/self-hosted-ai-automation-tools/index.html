Best self-hosted and open-source AI automation tools

Updated 24 Oct 2026 · Prices from vendor pages only · How we rank →

The short answer

Each of these AI automation tools can run on your own machine or servers, or is open source. n8n comes first: developer-friendly automation with unlimited steps per execution and a self-host option. The cheapest verified paid plan here is Flowise Starter ($35/month). 9 of the 10 have a free plan we could confirm. Every price below is from the vendor’s own page, checked 16–18 Oct 2026.

Ranked shortlist

  1. n8n: Developer-friendly automation with unlimited steps per execution and a self-host option. Plan: Not yet verified
  2. LangGraph: Developer framework for stateful, controllable agents. Plan: Developer: $0/seat per month
    1 seat, 5k base traces/month
  3. OpenAI Agents SDK: OpenAI's lightweight framework for multi-agent workflows. Plan: Open source (MIT)
  4. Google ADK: Google's open-source Agent Development Kit. Plan: Open source (Apache-2.0)
  5. Microsoft Agent Framework: Microsoft's open-source successor to AutoGen and Semantic Kernel agents. Plan: Open source (MIT)
  6. Pydantic AI: Type-safe Python agent framework from the Pydantic team. Plan: Open source (MIT)
  7. Mastra: Open-source TypeScript agent framework. Plan: Starter: $0/month
    100K observability events
  8. Dify: Open-source platform for building LLM apps and agent workflows visually. Plan: Sandbox: Free
    200 message credits
  9. Flowise: Open-source drag-and-drop builder for LLM agents. Plan: Free: $0/month
    2 flows & assistants
  10. Langflow: Open-source visual builder for agents and RAG. Plan: Free and open source, plus a free cloud account

Who should pick which

Pick n8n for technical teams building complex workflows and AI agents (€20/month (Starter, billed annually)); think twice if you want the simplest no-code setup. Pick LangGraph for developers building stateful, controllable AI agents in code (Developer: $0/seat per month). Watch out: the framework is free, but hosted deployment and tracing run on LangSmith with per-seat and usage charges. Pick OpenAI Agents SDK for developers building multi-agent workflows with tools and handoffs (free plan: Open source (MIT)). Watch out: you pay your model provider for usage. Pick Google ADK for developers building agents on Gemini and Google Cloud (free plan: Open source (Apache-2.0)). Watch out: you pay your model provider for usage. Pick Microsoft Agent Framework for .NET and Python teams taking agents to production on Microsoft's stack (free plan: Open source (MIT)). Watch out: you pay your model provider for usage. Pick Pydantic AI for python developers who want type-safe agents (free plan: Open source (MIT)). Watch out: a code library: you supply model API keys and hosting. Pick Mastra for TypeScript developers building agents (Starter: $0/month). Watch out: cloud Teams plan starts high.
