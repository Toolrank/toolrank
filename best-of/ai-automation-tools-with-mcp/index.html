Best AI automation tools with MCP support

Updated 18 Oct 2026 · Prices from vendor pages only · How we rank →

The short answer

Each of these AI automation tools supports the Model Context Protocol (MCP), so AI agents can connect to it. Zapier comes first: the largest app ecosystem with a free forever plan and simple task-based pricing. The cheapest verified paid plan here is Zapier Professional (from $19.99/month). 5 of the 7 have a free plan we could confirm. Every price below is from the vendor’s own page, checked 16–17 Oct 2026.

Ranked shortlist

  1. Zapier: The largest app ecosystem with a free forever plan and simple task-based pricing. Plan: Professional: from $19.99/month
    Multi-step Zaps
  2. n8n: Developer-friendly automation with unlimited steps per execution and a self-host option. Plan: Not yet verified
  3. Relevance AI: No-code platform for building AI agent teams. Plan: Not yet verified
  4. OpenAI Agents SDK: OpenAI's lightweight framework for multi-agent workflows. Plan: Open source (MIT)
  5. Google ADK: Google's open-source Agent Development Kit. Plan: Open source (Apache-2.0)
  6. Pydantic AI: Type-safe Python agent framework from the Pydantic team. Plan: Open source (MIT)
  7. Langflow: Open-source visual builder for agents and RAG. Plan: Free and open source, plus a free cloud account

Order follows ToolRank’s editorial ranking in Automation & Agents, filtered to tools that fit this page. Anything we couldn’t confirm on a vendor page says “Not yet verified”.

Who should pick which

Pick Zapier for non-technical teams automating across many SaaS apps (Professional: from $19.99/month); think twice if you run very high volumes and want self-hosting. Pick n8n for technical teams building complex workflows and AI agents (€20/month (Starter, billed annually)); think twice if you want the simplest no-code setup. Pick Relevance AI for companies building a team of AI agents for sales and operations (price not yet verified). Watch out: only the Enterprise plan was shown on the pricing page. Pick OpenAI Agents SDK for developers building multi-agent workflows with tools and handoffs (free plan: Open source (MIT)). Watch out: you pay your model provider for usage. Pick Google ADK for developers building agents on Gemini and Google Cloud (free plan: Open source (Apache-2.0)). Watch out: you pay your model provider for usage. Pick Pydantic AI for python developers who want type-safe agents (free plan: Open source (MIT)). Watch out: a code library: you supply model API keys and hosting. Pick Langflow for building and deploying agents and MCP servers visually (free plan: Free and open source, plus a free cloud account). Watch out: cloud limits are not published on the homepage.

FAQ

Which of these is cheapest?

Zapier Professional (from $19.99/month) is the lowest paid price we verified on this list (https://zapier.com/pricing, checked 16 Oct 2026). Check the vendor page for tax, billing period and usage limits.

Which of these have a free plan?

Zapier: 100 tasks/month; Zaps, Tables and Forms included; OpenAI Agents SDK: Open source (MIT); Google ADK: Open source (Apache-2.0); Pydantic AI: Open source (MIT); Langflow: Free and open source, plus a free cloud account.
