Best AI coding tools for $100 a month or less

Updated 17 Oct 2026 · Prices from vendor pages only · How we rank →

The short answer

Every tool here has a paid plan listed at $100 a month or less on its vendor's pricing page. Cursor comes first: a full AI-native editor with agents, cloud automations and code review, and a free tier to start. The cheapest verified paid plan here is Cursor Plus ($8/month). 8 of the 10 have a free plan we could confirm. Every price below is from the vendor’s own page, checked 16 Oct 2026.

Ranked shortlist

  1. Cursor: A full AI-native editor with agents, cloud automations and code review, and a free tier to start. Plan: Plus: $8/month
    Shared AI usage pool, Grok models only
  2. Claude Code: Anthropic's agentic coder runs in your terminal and repo, included with Claude paid plans. Plan: Claude Pro: $17/month annual or $20 monthly
  3. GitHub Copilot: Works in most major editors and in GitHub itself, from a free plan up to cloud agents and code review. Plan: Pro: $10/month
  4. Bolt.new: Generous token-based free tier and simple Pro/Teams pricing for in-browser app building. Plan: Pro: $25/month
    No daily limit, from 10M tokens/month, no branding
  5. Windsurf: Full agentic IDE with a free plan and unlimited Tab completions. Since June 2026 it ships as Devin Desktop, with a Kanban-style Agent Command Center that runs Devin and third-party ACP agents. Plan: Pro: $20/month
    Higher quotas, frontier models, Devin Cloud agents, extra usage at API pricing
  6. v0: Vercel's generator for React/Next.js UIs and apps, deploys to Vercel. Plan: Business: $100/user/month
  7. Replit: Replit Agent covers the whole loop in a browser: prompt, build, database, deploy, share. Paid plans include model credit. Plan: Core: $20/month ($18 annual)
    $20 toward powerful models, Plan mode, unlimited workspaces
  8. Devin: Delegates whole tickets to a cloud agent that plans, writes code and opens PRs. It connects to Slack, Linear, Jira and your git host, and since 2026 the self-serve plans start free. Plan: Pro: $20/month
    Higher quotas, frontier models, Devin Cloud agents, extra usage at API pricing
  9. Kiro: AWS's main coding product: spec-driven development, hooks and steering in a VS Code-based IDE plus CLI. It has a perpetual free tier, and it's the official successor to Amazon Q Developer. Plan: Pro: $20/user/month
  10. Zed: A very fast native editor that's free forever with your own keys or external agents like Claude Agent and Codex CLI. Pro is a low $10/month. Plan: Pro: $10/month
    Unlimited edit predictions, $5 tokens included, 14-day trial

Order follows ToolRank’s editorial ranking in Coding & App Building, filtered to tools that fit this page. Anything we couldn’t confirm on a vendor page says “Not yet verified”.

Who should pick which

Pick Cursor for developers who want an AI-first editor with agents and code review (Plus: $8/month); think twice if you want flat pricing that includes third-party models. Pick Claude Code for developers who prefer terminal-driven agents working across a repo (Claude Pro: $17/month annual or $20 monthly); think twice if you want a free tool or a graphical editor experience. Pick GitHub Copilot for teams already on GitHub who want AI in their existing IDE (Pro: $10/month); think twice if you want an AI-native editor rather than a plugin. Pick Bolt.new for quick full-stack prototypes and small business apps (Pro: $25/month); think twice if you'll burn through tokens on large projects without budget for upgrades. Pick Windsurf for developers who want a VS Code-style IDE that manages several local and cloud agents from one screen (Pro: $20/month); think twice if you want a stable, unchanging product, or a flat price with no usage overages. Pick v0 for generating React/Next.js UI and deploying to Vercel (Business: $100/user/month). Watch out: usage is credit-based. Pick Replit for founders and builders who want an agent to build and host an app without local setup (Core: $20/month ($18 annual)); think twice if you want to work in your own local repo and editor.

FAQ

Which of these is cheapest?

Cursor Plus ($8/month) is the lowest paid price we verified on this list (https://cursor.com/pricing, checked 16 Oct 2026). Check the vendor page for tax, billing period and usage limits.

Which of these have a free plan?

Cursor: Free: limited agent requests and limited chat requests; GitHub Copilot: Limited chat and agent usage; no code review or cloud agent; Bolt.new: 300K tokens/day, 1M tokens/month, Bolt branding, 10MB uploads, unlimited databases; Windsurf: Light agent quota, limited models, unlimited inline edits and Tab completions; v0: Free: $0/month, deploy apps to Vercel; Devin: Free plan: light quota, limited models (no cloud agents); Kiro: Perpetual free tier: 50 credits, Claude Sonnet 4.5 and open-weight models, rate-limited; Zed: Personal: free forever, unlimited with your own API keys or external agents.

How were these tools chosen?

They are the tools in ToolRank's rankings with a verified paid plan at or below $100/month (USD), confirmed on the vendor's own website on 16 Oct 2026. Tools we could not verify are left out rather than guessed, and anything unconfirmed is marked Not yet verified.
