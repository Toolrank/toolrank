Best AI coding tools for $20 a month or less

Updated 18 Oct 2026 · Prices from vendor pages only · How we rank →

The short answer

If you want the most capable tool for $20 a month or less, start with Cursor. Its Plus plan is $8/month, but it only includes Grok models. Claude Code comes with Claude Pro, at $17/month billed annually or $20 billed monthly. GitHub Copilot Pro ($10/month) is the pick if you want to stay in your current IDE. Zed Pro and JetBrains AI Pro are also $10/month. Devin Desktop (formerly Windsurf), Devin, Kiro, Amp and Replit Core all list a $20 plan. Every price below is from the vendor's own pricing page, checked 16 Oct 2026.

Ranked shortlist

  1. Cursor: A full AI-native editor with agents, cloud automations and code review, and a free tier to start. Plan: Plus: $8/month
    Shared AI usage pool, Grok models only
  2. Claude Code: Anthropic's agentic coder runs in your terminal and repo, included with Claude paid plans. Plan: Claude Pro: $17/month annual or $20 monthly
  3. GitHub Copilot: Works in most major editors and in GitHub itself, from a free plan up to cloud agents and code review. Plan: Pro: $10/month
  4. Windsurf: Full agentic IDE with a free plan and unlimited Tab completions. Since June 2026 it ships as Devin Desktop, with a Kanban-style Agent Command Center that runs Devin and third-party ACP agents. Plan: Pro: $20/month
    Higher quotas, frontier models, Devin Cloud agents, extra usage at API pricing
  5. Replit: Replit Agent covers the whole loop in a browser: prompt, build, database, deploy, share. Paid plans include model credit. Plan: Core: $20/month ($18 annual)
    $20 toward powerful models, Plan mode, unlimited workspaces
  6. Devin: Delegates whole tickets to a cloud agent that plans, writes code and opens PRs. It connects to Slack, Linear, Jira and your git host, and since 2026 the self-serve plans start free. Plan: Pro: $20/month
    Higher quotas, frontier models, Devin Cloud agents, extra usage at API pricing
  7. Kiro: AWS's main coding product: spec-driven development, hooks and steering in a VS Code-based IDE plus CLI. It has a perpetual free tier, and it's the official successor to Amazon Q Developer. Plan: Pro: $20/user/month
  8. Zed: A very fast native editor that's free forever with your own keys or external agents like Claude Agent and Codex CLI. Pro is a low $10/month. Plan: Pro: $10/month
    Unlimited edit predictions, $5 tokens included, 14-day trial
  9. Amp: A frontier coding agent that is free to start with your own keys or subscriptions, and has no Amp token fees on BYOK. It became an independent company after spinning out of Sourcegraph in Dec 2025. Plan: Individual: $20/month
    45,000 orb minutes
  10. JetBrains AI (Junie): Built into IntelliJ IDEA, PyCharm and the other JetBrains IDEs. JetBrains Air runs Junie, Claude Agent, Codex and other agents, and lets you bring your own keys. Plan: AI Pro: $10/month ($100/year)
    Personal pricing

Who should pick which

Pick Cursor Plus if price matters most and Grok models are fine for you. Pick Claude Code through Claude Pro if you work in the terminal and want Anthropic's agent. Pick GitHub Copilot Pro, JetBrains AI Pro or Zed Pro ($10 each) if you want to keep your editor: Copilot covers most IDEs, JetBrains AI covers JetBrains IDEs, and Zed is its own fast editor. Pick Devin Desktop, Devin, Kiro or Amp at $20 if you want agent-first workflows, and Replit Core if you want to build and host in the browser with no local setup. Watch for usage limits. Several of these plans bill anything over the included usage at API prices.

FAQ

What is the cheapest paid AI coding plan on this list?

Cursor Plus at $8/month, as listed on cursor.com/pricing on 16 Oct 2026. It only includes Grok models, and third-party models need Premium ($30/month).

Is Claude Code under $20 a month?

Claude Code is included in Claude Pro, which is $17/month billed annually or $20 billed monthly (claude.com/pricing, checked 16 Oct 2026). There is no standalone free tier.

Do $20 plans include unlimited usage?

Not on the plans we checked. Devin Desktop and Devin Pro use quotas, with extra usage billed at API prices. Kiro meters usage in credits. Zed Pro includes $5 of tokens. Read each vendor's limits before you pay.
