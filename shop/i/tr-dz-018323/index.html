ACR122U is a contactless connected smart card reader developed on 13.56MHz radio frequency technology. It is the first contactless smart card reader to pass CCID certification and it complies with ISO 14443 and ISO 18092 standards. It not only supports Mifare cards and Type A and Type B cards compliant with ISO 14443 standard, but also supports FeliCa and NFC tags.

The ACR122 is a full-speed (12 Mbps) USB device, which can read NFC tags at up to 424 bp, so this device reads and writes faster and more efficiently. Additionally, the ACR122U is also PC/SC compliant, enabling interoperability across different applications and platforms. It is slim and versatile, bringing you ultra-convenient enjoyment in applications such as electronic payment, access control, attendance and public transport.
