Simplecom SA102 NGFF M.2 (B Key) to 7mm 2.5" SATA Converter Enclosure Aluminium

SA102 NGFF M.2 to 7mm 2.5" SATA Enclosure let you convert your M.2 SSD into a standard 7mm 2.5 SATA form factor drive, so you can install M.2 SSD to a 2.5 SATA interface on PC or laptop or install it into a regular 2.5 SATA to USB enclosure.

Features

The durable Aluminium casing promises effective heat dissipation

Support specified M.2 SSD converted into a standard 2.5" SATA interface

Added protection for your M.2 SSD with enclosed housing

The speed and other properties is not changed, only form conversion interface

Size: 100 mm*70 mm*7 mm

Compatibility

Support the following form factor M.2 NGFF(SATA) B/B+M Key SSD:

Type 2242-D2-B-M: 42mm(L) x 22mm(W)

Type 2260-D2-B-M: 60mm(L) x 22mm(W)

Type 2280-D2-B-M: 80mm(L) x 22mm(W)

Note

Please Check Your M.2 SSD is SATA Channel or PCI-E Channel on manufacture website before ordering. It supports M.2 NGFF(SATA) B key and B+M Key SSD, M Key only or NVMe M.2 SSD are not supported.
