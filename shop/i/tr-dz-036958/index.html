Details

SA506 is a M.2 SSD to USB-C adapter that supports both NVMe and SATA protocol based M.2 SSDs. No need to worry about which type of M.2 SSD you have, this adapter converts both SATA and NVMe M.2 SSD to USB-C for easy access on your computer.
This adapter is plug and play and USB powered, no external power needed to operate. USB 3.2 Gen 2 interface for super-fast read and write speed up to 10Gbps. Its an ideal solution for for data migration, drive cloning and data backup. Designed for fast and easy access of M.2 SSD, this cable style adapter makes it easy to swap multiple M.2 SSDs without having to install them into a PC or enclosure.
