Details

Simplecom SA221 is a 2 in 1 Combo Adapter for both M.2 and mSATA SSD to SATA and USB 3.0 interface. Use this adapter to easily access 6 different size M.2 or mSATA SSDs via standard SATA or USB 3.0 port. Its an ideal solution for data backup and migration.

Specifications

mSATA + M.2 SSD 2 in 1 Combo Adapter

Detachable USB 3.0 cable, with SATA and USB 3.0 dual interface

LED indicates power and activity status

Support SATA Revision 3.2

PCI Express M.2 Spec. Revision 0.7, Version 1.0

PCI Express Mini Card Electromechanical Spec. 1.2

B Key M.2 interface, support B Key or B+M Key M.2 SSD

Thermal shutdown protection

Short circuit protection

In-rush current suppression

PWM synchronous buck converter Power IC

Support following form factor M.2(NGFF) SSD:

Type 2230-D2-B-M: 30mm(L) x 22mm(W)

Type 2242-D2-B-M: 42mm(L) x 22mm(W)

Type 2260-D2-B-M: 60mm(L) x 22mm(W)

Type 2280-D2-B-M: 80mm(L) x 22mm(W)

Support following form factor mSATA SSD:

Half size mSATA : 26.8mm(L) x 30mm(W)

Full size mSATA : 50.95mm(L) x 30mm(W)

Note:

If both M.2 mSATA SSD inserted at the same time the M.2 SSD will take priority. The mSATA SSD will be disabled until the M.2 SSD is removed.

The M.2 interface is B Key, M Key only or NVMeM.2 SSD are not supported.
