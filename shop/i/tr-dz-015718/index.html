Product Description

This 220V car power inverter features a dual LCD digital display so you can monitor output voltage and battery voltage in real time, with clear on-screen fault alerts for safer, more stable power conversion in vehicles and mobile applications.

Key Features

  • Dual LCD monitoring: Displays output voltage and battery voltage at a glance for better control and confidence.
  • On-screen fault prompts + audible alerts: Clear indications for common protections such as battery under/over-voltage, overload, over-temperature, and output short circuit.
  • Overload delay shutoff: Helps reduce overly sensitive protection when starting loads, improving usability for certain appliances.
  • Reverse polarity return protection: Added safety feature designed for small-power, non-professional users to help reduce connection mistakes.
  • Intelligent temperature-controlled fan: Oil-sealed fan runs based on operating temperature for quieter, more energy-efficient cooling.
  • MCU digital control: More accurate frequency and output voltage with fast protection-circuit response for dependable operation.
