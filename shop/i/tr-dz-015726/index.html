Product Description

Upgrade your above-ground pool plumbing with this Pool Hose Adapter (Pair, 25007 Series), designed to convert threaded Intex hose connections to clamp-style hoses for a secure, efficient water flow. Built from durable plastic and equipped with O-rings for a tighter seal, it helps your filter pump, chlorine generator, or saltwater system run smoothly with fewer leaks and less hassle.

Key Features

  • Threaded-to-clamp conversion: Converts threaded hoses to clamp style for easier, more secure connections.
  • Intex pump compatibility: Fits Intex filter pumps rated 1500/2000/2500/4000 GPH that use threaded hose fittings (25007 Series).
  • Works with sanitation systems: Suitable for Intex chlorine generators and salt systems using threaded hose connections.
  • Tight, leak-resistant seal: Integrated O-rings improve sealing for better circulation and efficiency.
  • Quick installation: Small end connects to a 1.25 hose; threaded end screws onto a 1.5 piston valve or filter pump.
  • Durable plastic build: Designed for reliable performance in above-ground pool setups.

Usage

Ideal for repairing or upgrading Intex above-ground pool hose setups—use it to connect your filter pump, piston valve, chlorine generator, or saltwater system where threaded fittings need to transition to clamp-style hoses. Simply attach the small end to a 1.25 hose, then screw the threaded end onto the 1.5 valve/pump port for a firm, efficient connection.
