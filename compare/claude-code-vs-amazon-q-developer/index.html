Who should pick which

New users can't choose it. Pick Claude Code for a terminal agent from Anthropic, from $17/month. FAQ

Can I still sign up for Amazon Q Developer?

No. AWS blocked new Q Developer accounts and subscriptions from 15 May 2026. Existing customers keep access until 30 Apr 2027.

What replaces Amazon Q Developer?

Kiro. AWS's announcement points users to Kiro (IDE and CLI), and the Q CLI has already become Kiro CLI.

Does Amazon Q use Claude?

Q Developer's pricing page lists access to the latest Claude models. AWS says the newest coding models are now only on Kiro.
