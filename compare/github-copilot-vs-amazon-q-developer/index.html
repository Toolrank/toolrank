GitHub Copilot vs Amazon Q Developer

Updated 16 Oct 2026 · Facts from vendor pages · How we rank →

Who should pick which

New users can only pick one of these: AWS stopped new Amazon Q Developer sign-ups on 15 May 2026, and plugins and paid subscriptions end on 30 Apr 2027. Pick GitHub Copilot for a supported assistant across VS Code, JetBrains, Visual Studio, Eclipse and Xcode, with a free plan and Pro at $10/month. Existing Q customers with Java or .NET upgrades in flight should finish them before the cutoff and plan a move. AWS's own path is Kiro.

FAQ

Is Amazon Q Developer being discontinued?

Yes, for the IDE plugins and paid subscriptions: end of support is 30 Apr 2027, and new sign-ups closed on 15 May 2026.

How did pricing compare?

Q Developer Pro was $19/user/month with a free tier of 50 agentic requests a month (existing accounts only now). Copilot Pro is $10/month, and Copilot also has a free plan.

What happens to Java upgrades in Q?

AWS says Java upgrades and .NET porting via the Q Developer IDE plugins need a paid subscription and won't be accessible after 30 Apr 2027.
