Updated 16 Oct 2026 · Facts from vendor pages · How we rank →

Who should pick which

This matchup has a twist: Cursor acquired Continue in 2026. Continue's GitHub repo is now read-only and 2.0.0 was its final release. Pick Cursor if you want a maintained product with ongoing updates. Continue's open-source extension still runs with your own model keys or local models, so it's only worth considering if you need a frozen, self-run setup and accept that nothing will be fixed. If you liked Continue's bring-your-own-model approach, Cline is the closest maintained alternative on ToolRank.

FAQ

Is Continue.dev discontinued?

Yes. continue.dev now says Continue was acquired by Cursor, and the GitHub README says the repository is no longer actively maintained and is read-only, with 2.0.0 as the final release.

Can I still use Continue?

The open-source code remains available, so you can keep running the extension with your own API keys or local models. It just won't get updates.

What should Continue users switch to?

Cursor (which acquired Continue) if you want an AI editor, or a maintained open-source agent like Cline if you want to keep bringing your own models.
